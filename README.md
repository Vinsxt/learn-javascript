# Learn JavaScript

A personal repository for learning and practicing **JavaScript**, following the **JavaScript Tutorial Full Course - Beginner to Pro** by [SuperSimpleDev](https://www.youtube.com/watch?v=EerdGm-ehJQ).

## What I've Learned

* JavaScript fundamentals and syntax
* Variables, data types, operators, and conditionals
* Functions and scope
* Objects and nested objects
* Arrays and loops
* DOM manipulation
* Event handling and user interactions
* Working with HTML and CSS using JavaScript
* Callback functions and asynchronous concepts
* Building interactive web applications

The repository contains my exercises and projects as I progress through the tutorial, with the goal of building a solid foundation in JavaScript and improving my ability to create interactive web applications.
